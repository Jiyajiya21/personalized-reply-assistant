# Changelog

All notable changes to Jiya Reply Assistant are documented here.

## 0.3.6 — 2026-10-09

- Limited availability suggestions to direct scheduling questions in the latest message.
- Prevented internal drafting labels from appearing in visible replies.
- Added output filtering for internal scheduling instructions.

## 0.3.5 — 2026-10-08

- Added automatic, editable availability suggestions.
- Moved tone and revision controls below the first generated draft.
- Added latest-message-only scheduling detection.

## 0.3.4 — 2026-10-08

- Added LinkedIn conversation scanning and message-box insertion.
- Made Gmail open a closed reply box before inserting a draft.
- Prevented replies when Jiya's own message is the latest in a thread.
- Strengthened sender-perspective detection for Gmail and LinkedIn.

## 0.3.0 — 2026-10-08

- Added one-click page scanning and automatic first-draft generation.
- Added Chrome on-device AI, optional local Ollama, and smart-template modes.
- Added copy and insert actions without automatic sending.
